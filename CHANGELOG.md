# Changelog

All notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.2.0] - 2026-08-12

### Changed

- Replaced the legacy launcher graphic with a modern market-globe and package-download mark.
- Added adaptive, round, and monochrome launcher icon variants.
- Added a dedicated Android notification icon.
- Added repository automation, security policy, contribution guidance, and CI.

## [1.1.0] - 2026-08-12

### Added

- Country flags and prioritized UK/US market choices.
- Delete-file lifecycle for completed downloads.
- Android Play-link handling and URL auto-population.
- Telegram recipient-picker sharing.
- Visible semantic version and per-build version code.

## [1.0.0] - 2026-08-11

### Added

- Initial package download, verification, and market-selection flow.
